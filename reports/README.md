# Research outputs

`figures/` contains the five original PNGs, whose matching plotting routines are present in recovered preprocessing and gem notebooks. They have not been regenerated during this review.

`baseline_reference/metrics.json` contains newly executed fixed mean/median reference scores for the exact 3 mm geometry holdout. It records source hash, target definitions and split counts. It is not a rerun of historical model training.

`docs/HISTORICAL_RESULTS.md` separately records selected saved model outputs with cell/protocol attribution. Comparison requires matching data, target, split and execution evidence.

`verification/research_audit.json` records the post-recovery source and preservation checks. The older project_audit report concerns the initial saved-file organization; it is archived locally because it predates the recovered code.

Prediction CSVs and `runs/` remain local. Predictions contain source observations and need the same sharing review as datasets.
