# Local tabular data

The two CSVs and seven Excel workbooks are retained here byte-for-byte. They are ignored by Git pending provenance and redistribution review. See `docs/DATA_CATALOG.md` for observed schemas and row counts, and `docs/file_manifest.csv` for exact hashes.

Original spreadsheet sheets, cell contents and file names were not changed. The plant-style CSV and CFD-derived tables are distinct products whose join relationships and physical units need verification. No automatic cleaning, unit conversion or imputation was performed.
