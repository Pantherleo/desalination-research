# Local RO simulation collection

Six original configuration directories and all HR/LR subdirectories remain intact. Each HDF5 file is accompanied by an XMF descriptor. Keep companions together because XMF HDF references use relative filenames.

The configuration names label spacer distances of 0.75, 1, 1.5, 2, 2.5 and 3 mm. These names do not verify physical units for the stored fields, solver settings or independence of image indices.

The files are ignored by Git pending source and redistribution review. An approved distribution source is not yet documented. Compare recovered files against `docs/file_manifest.csv` before using them.
