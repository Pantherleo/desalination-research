# Experiment record

| Field | Required record |
| --- | --- |
| Research question | Target, intended use and hypothesis |
| Authors and date | Confirmed contributors and execution date |
| Code version | Git revision and entry point |
| Source data | Provider, URL, access date, permissions and checksums |
| Physical setup | Geometry, spacer definition, boundary conditions, solver and units |
| Numerical validation | Mesh convergence, conservation and reference comparison |
| Observation identity | Independent run, configuration, timestep and resolution mapping |
| Target and features | Definitions, units and prediction-time availability |
| Transformations | Derivations, missing-data policy and training-only fit scope |
| Splits | Exact group membership and leakage checks |
| Baselines | Training-only reference predictors under the same split |
| Model and tuning | Parameters, seeds and nested validation protocol |
| Environment | Python, dependencies, operating system and hardware |
| Results | Held-out errors, units, group breakdown and uncertainty |
| Artifacts | Output locations, hashes and approved retrieval instructions |
| Limitations | Failure cases and interpolation/extrapolation scope |
| Review | Reproducer, date and commands actually executed |
